1What it is

Prototype pollution happens when an app copies user data into an object without checking the keys. In JavaScript, every object inherits from one shared parent, and the special key "__proto__" points to it. If an attacker writes there, they change every object in the app at once.

4Why it matters

    
A harmless settings form can turn into admin access, crashes, or even running attacker code, because the fake property appears on objects the app trusts.
Real incident: in 2019 researchers found prototype pollution bugs in lodash, a JavaScript library used by a huge number of projects. Every app using the broken function had to update.
